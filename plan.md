# Better Lineup Plan

## Project Overview
Dự án **Better Lineup** giúp quản lý và tối ưu hóa đội hình (lineup), tích hợp Frontend Next.js và Backend Spring Boot kết nối database MySQL.

## Tech Stack
- **Frontend (FE):** Next.js (App Router, TypeScript, TailwindCSS)
- **Backend (BE):** Java Spring Boot (Java 21, Maven)
- **Database (DB):** MySQL
